# Omarchy Store browser extension

The Omarchy Store in your browser's side panel. Works in Chromium, Chrome, Brave, Edge and Vivaldi.

- Browse and search the store, by category
- Copy an app's install command with one click, then paste it in a terminal
- Right-click any selected text to search the store

Privacy: no tracking, no analytics. See https://omarchystore.com/privacy/

## Build

```bash
zip -r dist/omarchy-store-extension.zip manifest.json src assets/icons
```
